Offline static web app that turns a photo + caption into a GTA-style poster cover. Five layouts, six grades, per-panel crop/position, title effects, badges, three-size PNG export. OFL fonts only, no Rockstar assets.

Run locally: node serve.ts then open http://localhost:8080.
